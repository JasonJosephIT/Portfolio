# Portfolio context

- **Visibility tag**: one of `public`, `context-only`, `private`, set on each Open Thoughts project and claim. Only `public` items may reach the Portfolio or the chatbot. New items start `private`.
- **Public record**: the approved, redacted, Claude-drafted text for one `public` item (or the profile) that Open Thoughts holds in its public section. The internal note is never published as is.
- **Bundle**: the set of approved public records, plus enrichment (relations), that the Portfolio pulls from Open Thoughts.
- **Profile**: the public record about Jason himself, drawn from the Map's resume-safe items.
