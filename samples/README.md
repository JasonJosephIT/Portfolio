# Sample bundle

Placeholder projects (Harbor, Lumen, Ledger, Tidepool) written to the eight-section standard, with mock
interface screenshots in `public/sample-media/`. It exists to review layout before the real, enriched
records arrive. None of it describes real work: do not publish it.

Preview it: `BUNDLE_DIR=samples/bundle npm run dev`
It validates like any bundle: `validateBundle("samples/bundle")`.
