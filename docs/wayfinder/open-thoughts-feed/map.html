Decisions so far

Destination, tracker, approval starting point, out-of-scope list and chatbot corpus default were settled with Jason while charting (see Notes).

Bot check on the chatbot: Cloudflare Turnstile (Jason, 2026-10-16). Its pricing is to be confirmed in the guardrails ticket.

What do the Cloudflare pieces cost and allow?: Use Workers Static Assets, not Pages, for new projects; a Worker (via @astrojs/cloudflare) is needed for the chatbot and cron.

What is industry standard for a public RAG chatbot's safety?: Latest OWASP LLM list is 2025; key items LLM01 injection, LLM02 disclosure, LLM08 vector weaknesses, LLM09 misinformation, LLM10 unbounded consumption; RAG alone does not stop injection.

What is the public face?: Items carry public/context-only/private tags (new = private); enrichment drafts a separate public record that Jason approves; grounded in the note, redaction blocks, names need a tick; a profile record too.

What is the bundle format?: Directory bundle (manifest, per-record JSON, relations.json, docs as markdown), OT owns the JSON Schema and both sides validate, full snapshots with slug ids, media by reference, integer schema_version.

How does Portfolio pull the bundle?: Export button in OT, scheduled local pull opens a PR, bundle committed to git; index rebuilt from it on each deploy.

How does approval work in the review desk?: One publish card per record (tag+text+relations), new `revise` kind with diff, stale records stay live until revised, human-only export gate with re-scan.

How does Open Thoughts enrich the bundle with relations?: Four sources, four edge types (uses, part-of, built-with, related-to), scripts propose and Claude selects, approved with the record; tags free-form first then controlled; Jev + Claude API wanted.

What is the site architecture on Cloudflare?: One Worker with static assets, fully prerendered; separate chatbot Worker; Astro at repo root with content collections; preview per PR; workers.dev first.

Which engines do the enrichment?: Opus drafts with Jason's writing skill, Jev double-checks, Haiku 5.5 high fixes issues; private never leaves without a per-item consider action; Keychain keys, monthly cap; pause rather than switch engines.

What does the chatbot read and how is it built?: Bundle-only corpus chunked by heading, namespace per bundle hash, Workers AI behind AI Gateway, answers only from retrieved chunks with citations; conversations stored (guardrails decides retention and notice).

What guardrails does the chatbot ship with?: Chats in D1 only, 90-day retention, visible notice, Turnstile + rate/spend limits + kill switch, non-streaming with Guardrails, eval set in CI plus manual red-team gate.

What docs does Open Thoughts generate and how do they ship?: Features + decisions docs per public project, same pipeline and approval (kind doc), shipped in the bundle as markdown, stale rule as records.

How do we migrate from static HTML and the staged changes?: Land staged changes first on a branch; phased PRs A-F; clean URLs with 301s; Art hand-managed; retire admin/Supabase/Instatic without deleting the Supabase project; static-final tag for rollback.

How are prototypes hosted, video first?: Deferred by Jason; see Not yet specified.
